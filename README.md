# Recipe Vault (`recipe-vault`)

An interactive recipe exploration and meal planning web application built with React, Vite, and Tailwind CSS. Features multi-criteria searching, category tags, interactive recipe modals, and a local bookmarking system.

## Features

- **Search & Filter:** Search recipes by title, ingredients, or cuisine category.
- **Recipe Modal:** View detailed step-by-step preparation instructions, cooking time, and ingredients.
- **Favorites Vault:** Save and remove bookmarked recipes stored in `localStorage`.
- **Responsive UI:** Clean grid layout styled with modern utility-first CSS and vector iconography.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
